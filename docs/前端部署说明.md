# 前端部署说明（Agent4 · 文档输出）

> 面向：答辩演示操作者、后端联调同学。
> 前置阅读：[`../README.md`](../README.md)；接口对接细节见 [`接口对接说明.md`](接口对接说明.md)。
> 本文件所有命令、包名、文件路径均已与 [`../requirements.txt`](../requirements.txt)、[`../config.py`](../config.py)、[`../app.py`](../app.py) 逐一核对一致。

---

## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| Python | 3.9+（推荐 3.10–3.12），`python` / `pip` 已加入 PATH |
| 网络 | 可访问 PyPI（安装依赖时）；联调时本机可访问后端地址 |
| 后端 | FastAPI 后端（默认 `http://127.0.0.1:8000`）。仅演示可不开后端（演示模式，见第 8 节） |
| 磁盘/内存 | 常规即可（Streamlit 单页应用，无特殊要求） |

---

## 2. 第一步：创建虚拟环境

**Windows（CMD 或 PowerShell）：**

```bat
cd D:\agent\ledger-frontend
python -m venv .venv
.venv\Scripts\activate
```

**macOS / Linux：**

```bash
cd /path/to/ledger-frontend
python3 -m venv .venv
source .venv/bin/activate
```

> 成功标志：命令提示符前出现 `(.venv)`。后续所有命令均在该虚拟环境中执行。

---

## 3. 第二步：安装依赖

```bash
pip install -r requirements.txt
```

锁定版本（[`requirements.txt`](../requirements.txt) 实况）：

| 包 | 版本 | 用途 |
| --- | --- | --- |
| streamlit | ==1.41.1 | Web 框架（锁旧版以避开 1.49+ 的 `use_container_width` 弃用警告） |
| requests | ==2.32.3 | HTTP 客户端（`services/api_client.py` 真实接口调用） |
| plotly | ==5.24.1 | 图表（分类占比环形图 + 月度趋势柱状图） |
| pandas | ==2.2.3 | 表格展示（流水列表 / 查账统计表 / 预算明细表） |

- 验证：`streamlit --version` 应输出 `Streamlit, version 1.41.1`；或 `pip list` 核对四件套版本。
- 安装慢/超时：换国内镜像 `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`。
- `python-dotenv`、`streamlit-echarts` 当前代码未使用（requirements.txt 中以注释说明），无需安装。

## 4. 第三步：启动后端（联调前提，纯演示可跳过）

后端为 FastAPI（其他组已完成），启动方式以后端项目实际命令为准，示例：

```bash
uvicorn main:app --host 127.0.0.1 --port 8000
```

验证后端已就绪：

- 浏览器打开 `http://127.0.0.1:8000/docs` → 能看到 Swagger UI 与全部接口；
- 或访问 `http://127.0.0.1:8000/health` → 返回 `200 {"status": "ok", ...}`。

> 后端不在本机 8000 端口（或部署在别的机器）时，用第 6 节的方式给前端配置后端地址。

---

## 5. 第四步：启动前端

```bash
cd D:\agent\ledger-frontend
streamlit run app.py
```

- 浏览器访问 Streamlit 提示的地址（默认 **http://localhost:8501**）。
- 预期行为：
  - 页面打开后自动执行一次 `GET /health` 探测（带「正在连接后端服务…」spinner）；
  - 探测成功 → 左侧概览侧边栏 + 主区域 6 个 Section 卡片（①自然语言记账→②小票OCR→③流水列表→④消费图表→⑤自然语言查账→⑥预算预警）；
  - 探测失败 → 显示「无法连接后端服务」引导页（可到左侧「高级设置」改地址或勾选演示模式）。
- 端口自定义：`streamlit run app.py --server.port 8502`。
- 服务器/无头运行：Streamlit 默认即 headless，远程访问可加 `--server.address 0.0.0.0`。

## 6. 后端地址配置（三种方式，优先级从高到低）

| 优先级 | 方式 | 操作 |
| --- | --- | --- |
| 1（最高） | 运行时覆盖 | 页面左侧「高级设置」→「后端地址」文本框输入，修改后**自动重新探测连通性**，无需刷新页面 |
| 2 | 环境变量 `LEDGER_API_BASE_URL` | Windows CMD：`set LEDGER_API_BASE_URL=http://192.168.1.10:8000`；PowerShell：`$env:LEDGER_API_BASE_URL="http://192.168.1.10:8000"`；macOS/Linux：`export LEDGER_API_BASE_URL=...` |
| 3 | 配置文件 | [`../config.py`](../config.py) 常量 `API_BASE_URL`（默认 `http://127.0.0.1:8000`） |

约定：页面代码**禁止硬编码 URL**，一律从 `config.py` 读取。

## 7. 与后端联调步骤（从 /docs 核对字段）

> ⚠️ 本组开发环境无法访问后端 `/docs`，15 个接口的路径与字段均为推导默认值，**首次联调必须按以下步骤核对**。

1. **启动后端**，浏览器打开 `http://127.0.0.1:8000/docs`；
2. **逐项核对** [`接口对接说明.md`](接口对接说明.md) 第 5 节「联调检查清单」的 12 项：
   接口路径、金额字段名（`amount_cents` 整数分）、日期字段（`occurred_at` / `YYYY-MM-DD`）、分页参数（`limit/offset`）、错误响应体结构、parse 返回字段、删除返回（200+body 或 204）、OCR 确认链路、统计接口 `ratio`/空月补 0、query 的 `table` 结构、`budgets/status` 与 `level` 取值、summary 月份参数名；
3. **不一致时的修改位置**（页面代码无需改动）：
   - 接口**路径**不一致 → 改 [`../config.py`](../config.py) 的 12 个 `PATH_*` 常量；
   - **参数 / 字段 / 响应结构**不一致 → 改 [`../services/api_client.py`](../services/api_client.py) 对应函数（15 个接口函数 docstring 均标注了后端路径与「需后端配合」字段）；
4. **改完重启前端**（`Ctrl+C` 后重新 `streamlit run app.py`），按第 9 节冒烟步骤验证。

## 8. 演示模式（无后端答辩演示兜底）

后端未启动/现场无网络时，可用演示模式：全部接口返回内置示例数据（近 6 个月、按当天日期动态生成），**不发真实 HTTP 请求**；增删改在内存中生效，页面各区块联动。开启方式（优先级从高到低）：

1. 页面左侧「高级设置」勾选「演示模式（DEMO，使用内置示例数据）」；
2. 环境变量（Windows CMD）：

   ```bat
   set LEDGER_DEMO_MODE=1 && streamlit run app.py
   ```

   PowerShell：

   ```powershell
   $env:LEDGER_DEMO_MODE="1"; streamlit run app.py
   ```

   macOS / Linux：`LEDGER_DEMO_MODE=1 streamlit run app.py`
3. [`../config.py`](../config.py) 常量 `DEMO_MODE = True`。

> 开启成功后页头显示蓝色提示条「当前为演示模式（DEMO）」。注意：演示数据在内存中，**刷新页面即重置**；真实数据永远走 HTTP。

## 10. 常见问题排查（FAQ）

### 10.1 前端 8501 端口被占用

- 现象：启动报错 `Port 8501 is already in use`。
- 处理：换端口 `streamlit run app.py --server.port 8502`，访问 `http://localhost:8502`。

### 10.2 后端 8000 端口被占用

- 处理：后端换端口启动（如 `uvicorn main:app --port 8001`），然后前端左侧「高级设置」把后端地址改为 `http://127.0.0.1:8001`（自动重探测）。

### 10.3 页面显示「无法连接后端服务」

- 原因：后端未启动 / 已崩溃 / 地址不对 / 防火墙拦截。
- 排查：① 浏览器直接访问 `http://127.0.0.1:8000/health` 验证后端；② 检查「高级设置」里的后端地址；③ 后端在其他机器时放行对应端口，并用环境变量或侧边栏配置该地址。

### 10.4 接口 404（Not Found）

- 原因：接口路径与后端实际路由不一致（本组为推导默认值）。
- 处理：对照 `http://127.0.0.1:8000/docs`，修改 [`../config.py`](../config.py) 中对应的 `PATH_*` 常量（共 12 个），重启前端。

### 10.5 接口 422 / 字段校验失败

- 现象：提示「输入格式有误：字段 xxx …」（前端已自动定位第一个字段）。
- 处理：对照 `/docs` 的 Request body / Query 参数，检查字段名与格式（金额 `amount_cents` 整数分、日期 `YYYY-MM-DD` 等），修改 [`../services/api_client.py`](../services/api_client.py) 对应函数。

### 10.6 浏览器 CORS 报错？

- **正常不会出现**：本前端由 Streamlit 服务器用 Python `requests` 直连后端，请求不经过浏览器，不受浏览器同源策略 / CORS 限制，后端无需配置 CORS。
- 若仍遇到 CORS 报错，说明请求来自浏览器（例如将来改用自定义前端组件或浏览器直连），此时才需要后端 FastAPI 的 `CORSMiddleware` 放行对应 `Origin`。

### 10.7 满屏 `use_container_width` 弃用警告

- 原因：Streamlit 升级到 1.49+。
- 处理：保持锁定版本 `streamlit==1.41.1`（`pip install -r requirements.txt`）；若必须升级，全局替换 `use_container_width` 参数（改用 `width="stretch"`）。

### 10.8 演示模式没生效

- 检查优先级：侧边栏勾选 > 环境变量 `LEDGER_DEMO_MODE`（取值 `1/true/yes/on`）> `config.DEMO_MODE`。
- 生效标志：页头出现蓝色提示条「当前为演示模式（DEMO）」。设置环境变量后需重新启动 `streamlit run app.py`。

### 10.9 pip 安装失败 / 依赖冲突

- 网络超时：换镜像源重试（见第 3 节）。
- 版本冲突：删除 `.venv` 重建虚拟环境后重新安装，避免与本机其他项目混用环境。

### 10.10 页面样式或图表不显示

- 处理：确认四件套版本正确安装（`pip list` 对照第 3 节表格）；浏览器强刷（Ctrl+F5）；确认未将 Streamlit 升级到 1.49+。
